2. Felépítések (F1 – F3)

F1
Konfiguráció elsőként
Egyszeri setup a tantárgy elején. B1 + B2 meta-prompt elkészül, majd minden lekérdezés ezek alapján fut. Az 1–2. hét kézi finomítással stabilizálja a meta-promptokat. F3-ra kombinálható: 1–2 hét F1-gyel, utána F3.
Tengelyeken elfoglalt pozíció
A — rugalmas (A0/A2/A4) B — B1 + B2 standard C — 3 kimenet (Mind + Chat + Quiz) D — D1 beugró / D3 optimális E — kétindexes (E3)
✔ Erőssége
Egyszeri konfig; audit-trail az első lekérdezéstől; alacsony setup-küszöb
⚠ Gyengéje
Rossz B1/B2 sok átírást okoz; javítás nem fut vissza régi válaszokra
F2
Két-csatorna alap
MinerU minden forráson kötelező (A4). Szöveg (MD) és képhalmaz két külön NLM-csatornán kerül be. Data Tables (Pro/Ultra) az ábrahorgony-kigyűjtés eszköze. D3 plugin bulk-add képességgel egyszerűsíti a kép-feltöltést.
Tengelyeken elfoglalt pozíció
A — A4 kötelező (MinerU) B — B1 + B2 + csatorna-konvenció C — 4 kimenet (+ Data Tables) D — D3 optimális (bulk-add) E — kétindexes + ábrahorgony (E4)
✔ Erőssége
Explicit ábrahorgony; Data Tables strukturált citáció; D3 bulk-add
⚠ Gyengéje
50-forrás-limit képekkel gyorsan telhet; extra MinerU előkészítési idő
F3
Iteratív, hierarchia-driven
Egyetlen Claude-prompt vezérli a heti vázlat H3-szintű alfejezetein az iterációt. D4 connector automatikusan lekérdez, 3-körös follow-up ha a válasz hiányos. Stabil heti vázlat előfeltétel. Javasolt: 1–2 hét F1-gyel, utána F3.
Tengelyeken elfoglalt pozíció
A — A4 (mint F2) B — B1 + B2 + iteratív kiegészítés C — 3 kimenet (Chat iteratív) D — D4 ideális (D3 is működik) E — kétindexes + 3-körös follow-up (E5)
✔ Erőssége
Leginkább auto-pilot (~90 perc/hét); 3-körös follow-up konvergál
⚠ Gyengéje
D4 fejlesztői mindset; stabil heti vázlat előfeltétel; Cowork Pro/Max

3. F × D kompatibilitási mátrix

F \ D D0 — manuális D1 — BibCit D2 — Apify D3 — cowork plugin D4 — connector
F1 — konfig elsőként fallback jó kezdés overkill ✅ optimális overkill
F2 — két-csatorna nehéz (sok kép) OK OK (batch) ✅ optimális (bulk-add) részben
F3 — hierarchia-driven nem ajánlott nem (manuális) részben ✅ optimális ✅ optimális (3-körös)

D3 (notebooklm-cowork plugin) mindhárom F-re alapcsapat. Ha valamit először telepítesz, ez legyen. D4 (notebooklm-connector) csak F3-hoz éri meg.
